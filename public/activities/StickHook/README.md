# 🎮 Stickman Hook

> A dynamic web-based recreation of the addictive Stickman Hook game, built entirely with HTML5 and modern web technologies.

## About

Stickman Hook is an exciting action-packed game where players control a stickman character swinging from hook to hook, navigating through challenging obstacles and levels. This is a faithful HTML port bringing the mobile gaming experience directly to your browser.

## ✨ Features

- 🎯 **Smooth Gameplay** - Fluid swinging mechanics and responsive controls
- 🎨 **Vibrant Graphics** - Colorful and engaging visual design
- 📱 **Cross-Platform** - Play on desktop, tablet, or mobile browsers
- ⚡ **Lightweight** - Pure HTML/CSS/JavaScript, no heavy dependencies
- 🏆 **Progressive Difficulty** - Increasingly challenging levels as you progress
- 🎵 **Immersive Experience** - Sound effects and dynamic feedback

## 🎮 How to Play

1. Open the game in your web browser
2. Click or tap to make the stickman grab onto hooks
3. Swing from hook to hook to navigate through each level
4. Avoid obstacles and reach the end of each stage
5. Progress through multiple levels of increasing difficulty

## 🚀 Getting Started

Simply open `index.html` in your web browser and start playing!

### Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- No external dependencies required

## 🛠️ Technologies

- **HTML5** - Game structure and canvas
- **CSS3** - Styling and animations
- **JavaScript** - Game logic and mechanics

## 📝 Game Controls

| Input | Action |
|-------|--------|
| **Space Bar** | Grab hook |
| **Touch Tap** | Grab hook (mobile) |
| **Release** | Let go of hook |

## 🎯 Objectives

- Navigate through challenging level designs
- Master the swinging mechanics
- Complete all levels without falling
- Achieve the fastest times
